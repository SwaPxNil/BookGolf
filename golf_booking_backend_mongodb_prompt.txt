----------------------------------
FEATURE REQUIREMENTS
----------------------------------

1. TEE TIME BOOKING
- GET /courses
- GET /courses/:id/tee-times (only AVAILABLE)
- POST /tee-times/book
- Prevent double booking (atomic operation)

2. COACH & LESSONS
- GET /coaches
- GET /coaches/:id/lessons
- POST /coach-lessons/book
- DELETE /coach-lessons/:booking_id (cancel)

3. CADDIE BOOKING
- GET /caddies
- GET /caddies/:id/availability
- POST /caddies/book
- DELETE /caddies/:booking_id

4. GAME HISTORY
- GET /users/me/rounds
- GET /rounds/:id (final score details)

5. HANDICAP CALCULATION
- POST /handicap/calculate
  Body:
  {
    recent_score_1,
    recent_score_2,
    course_id
  }

Calculation logic:
- Use course_rating and slope_rating
- Use average of last 2 scores
- Return:
  {
    course_name,
    handicap_value
  }

6. COURSE ADMIN
(Only COURSE_ADMIN role)
- GET /admin/coaches
- POST /admin/coaches
- PUT /admin/coaches/:id
- DELETE /admin/coaches/:id
- Same CRUD for Caddies
- View lessons

7. SUPER ADMIN
(Only SUPER_ADMIN role)
- GET /super-admin/course-admins
- Approve / reject courses
- GET /super-admin/logs
